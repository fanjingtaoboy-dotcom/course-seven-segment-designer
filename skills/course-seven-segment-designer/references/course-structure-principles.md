# 课程结构原理与方法

## Core Rule

When mining mature scripts, feedback notes, or corrected outputs, extract reusable course-structure principles before describing the case. The skill should improve by learning how teaching structure works, not by memorizing a single domain, teacher style, or private transcript.

Use this order:

```text
原理 -> 原则 -> 方法 -> 检查项 -> 脱敏样例
```

Do not store raw private transcripts, real names, institution names, learner details, phone numbers, order data, or proprietary wording in public skill resources.

## 四层抽象

Use four levels when converting material into reusable skill rules:

| Level | Purpose | Keep | Avoid |
|---|---|---|---|
| 原理 | explain why course structure works | learner psychology, attention, memory, ability transfer | teacher personality or industry-only facts |
| 原则 | decide what must be true | must create learning reason before pain, must make principle retellable | vague praise such as "more interactive" |
| 方法 | show how to edit | add scene gap, compress model, insert validation step | raw transcript paragraphs |
| 检查项 | make future diagnosis stable | yes/no or qualified/partial/missing checks | one-off stylistic preferences |

Only promote a case detail into a rule when it generalizes across at least two likely course types or explains a repeated diagnostic failure.

## 结构功能优先

Judge every paragraph by its function, not by its heading:

```text
它让学员发生了什么变化？
它完成了哪一个二级任务？
它是否为下一段降低阻力？
```

Typical rule:

| Surface content | Do not assume | Function test |
|---|---|---|
| welcome and chat | 暖场合格 | does it lead to topic, learner scene, and reason to listen |
| problem collection | 引发需求合格 | does it turn scattered wishes into learning necessity |
| consequence language | 挖掘痛点合格 | does it explain cause, misconception, and why this lesson is needed |
| many concepts | 原理讲解合格 | can learners retell the model and use it to judge |
| teacher demo | 实操演示合格 | does it show steps, middle judgment, validation, mistakes, and transfer |
| content recap | 总结回顾合格 | does it compress into memory structure |
| homework assignment | 结尾升华合格 | does it give motive, standard, low resistance, and feedback path |

## 学员心理推进

Treat the seven segments as a psychological route:

```text
不熟悉/未进入 -> 愿意听 -> 觉得和我有关 -> 觉得必须解决 -> 理解为什么 -> 知道怎么做 -> 记住并行动
```

The best diagnosis identifies where the learner gets stuck:

| Stuck point | Usually caused by | Upgrade move |
|---|---|---|
| 不想听 | weak opening trust or topic orientation | name learner scene, promise a concrete lesson gain, enter topic faster |
| 感觉无关 | weak demand activation | use real scenes, goals, self-test, or contrast |
| 不急 | weak pain excavation | show cause, cost, misconception, and learning necessity |
| 听不懂 | knowledge dumping | define fewer concepts and form one model |
| 不会用 | weak practice loop | add object, steps, judgment, validation, mistake reminders |
| 记不住 | directory recap | compress into formula, checklist, or three-point model |
| 不行动 | task-only ending | connect gain, value, standard, next step, and feedback |

## 需求到痛点的推进

Do not jump from learner wishes directly into teaching. A qualified course usually needs this progression:

```text
表层愿望 -> 共同目标 -> 能力缺口 -> 旧做法失败 -> 原因/误区 -> 今天必须学的关键能力
```

Common failure:

```text
学员说想解决 X -> 老师开始讲知识
```

Better structure:

```text
学员想解决 X -> 多数人卡在 Y 判断 -> 旧做法只处理表面 -> 不学会 Z 会反复卡住 -> 今天先掌握 Z
```

Use this as a diagnostic question:

```text
学员是否知道“为什么是今天这节课来解决这个问题”，而不是只知道“这个主题重要”？
```

## 原理可复述

Principle explanation is qualified only when it becomes a learner-usable model:

| Requirement | Check |
|---|---|
| 核心概念少 | are there only the concepts needed for this lesson |
| 机制清楚 | can learners explain why the problem happens |
| 判断标准明确 | do learners know what to observe, compare, or test |
| 流程可复述 | can learners retell the method in steps |
| 边界清楚 | do learners know when not to overuse it |
| 能转入实操 | does the model directly guide the case or action |

Do not reward expertise density alone. More knowledge can lower the score if it breaks memory, judgment, or application.

## 实操可迁移

For delivery classes and training-camp single lessons, the strongest structural upgrade often sits in the practice loop.

Use this chain:

```text
应用对象 -> 标准步骤 -> 中间判断 -> 前后验证 -> 易错提醒 -> 课后迁移
```

Minimum checks:

1. Learners know what exact object or scene the method applies to.
2. Learners can imitate the sequence without teacher presence.
3. Learners know how to judge whether they are doing it correctly during execution.
4. Learners can compare before and after using the same standard.
5. Learners know the main mistake and boundary.
6. Learners know how to submit homework or repeat the action.

## 记忆与行动闭环

Summary and ending are not administrative leftovers. They decide whether in-class value becomes after-class behavior.

Qualified summary:

```text
one main line + 1-3 key points + mistake reminder + answer to opening problem
```

Qualified ending:

```text
today's gain -> deeper value -> one low-resistance action -> action standard -> feedback or next lesson
```

Common upgrade:

| Weak version | Better version |
|---|---|
| "今天讲了很多，大家回去练" | "今晚只做一件事：按 X 标准完成 Y，拍照/提交给助教，重点看 Z 是否达标" |
| "明天更重要，一定要来" | "今天你会了 A，但还会卡在 B；明天解决 B，所以今天作业会成为明天的入口" |

## 主线聚焦

A high-quality course has one visible main line. Authority, cases, rewards, interaction, discipline, and previews are useful only when they serve the main line.

Flag main-line crowding when:

1. Learners remember rewards or teacher stories more than the method.
2. Cases prove the teacher is strong but do not help learners understand or practice.
3. Management reminders interrupt the pain-principle-practice chain.
4. Too many side problems make the lesson goal unstable.
5. Next-session or sales prompts replace the summary.

Upgrade by naming the one lesson task:

```text
这节课只解决一个核心能力：让学员能判断/完成/说出/练会 X。
```

## 课型适配

Keep the seven segments fixed, but change weight by course type:

| Course type | Heavier segments | Score risk |
|---|---|---|
| 训练营单课 | demand, practice, homework, next-session link | reward pressure replaces learning reason |
| 交付课 | principle, practice, validation, boundary | content is mature but summary/action weak |
| 公开课 | opening, demand, pain, principle clarity | too much authority or fear before method |
| 专题课 | main-line focus, model compression, case transfer | topic branches crowd learner memory |
| 练习课 | demonstration, feedback, mistake correction | teacher does it but learners cannot self-check |

For the user's current priority order, treat delivery effect as primary unless stated otherwise; next-session attendance and homework should support the learning loop.

## 教学与销讲分流

When a full transcript includes selling, separate the two chains before judging:

```text
教学主链：让学员听懂、学会、记住、愿意练习
销讲主链：让学员相信、觉得值、敢买、现在行动
```

Do not treat sales conversion as a course eighth segment. Use the sales-conversion bridge when the handoff matters, and recommend `$sales-conversion-eight-segment` for price, offer, discount, objection, quota, deposit, enrollment, or case-proof diagnosis.

## 从案例提炼规则

Use this mining process:

```text
1. Identify the concrete observation.
2. State the structural failure or strength.
3. Link it to one segment and one secondary task.
4. Explain the learner psychological mechanism.
5. Convert it into a reusable check.
6. Add only anonymized or synthetic examples.
```

Do not promote a rule if it only reflects:

- one teacher's speaking style
- one institution's internal operation
- one unverified learner case
- private wording that cannot be shared
- data that is not comparable across learner groups

## 输出要求

For principle extraction or skill-improvement requests, output:

```text
一、可沉淀的结构原理
二、可转成诊断规则的判断原则
三、可转成改稿动作的方法
四、应加入 skill 的检查项
五、脱敏样例或合成示例
六、不建议沉淀的案例细节
```

Keep critique strict but portable. A good conclusion should help diagnose the next unrelated course, not only explain the current transcript.

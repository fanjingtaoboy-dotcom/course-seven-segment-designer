# Production Label Map

Use this reference when a transcript has operational headings or live-class labels that do not match the seven-segment framework directly.

## Mapping Principle

Classify content by function, not by title:

```text
surface label -> actual learner effect -> seven-segment function -> qualified or interference
```

## Common Labels

| Source label | Possible seven-segment function | Qualified when | Interference when |
|---|---|---|---|
| 开场, 设备测试, 欢迎 | 暖场破冰 | gets learners ready and enters topic quickly | repeats waiting and delays topic |
| 老师介绍, 传承介绍, 资历介绍 | 暖场破冰 / 原理讲解 / 结尾升华 | builds relevant trust or explains method origin briefly | becomes authority dumping |
| 到课福利, 抽奖, 完课奖励 | 暖场破冰 / 结尾升华 | supports attendance or homework without stealing focus | appears repeatedly in core teaching |
| 建立学习目标, 愿望互动 | 引发需求 | turns wishes into today's learning reason | only collects goals or asks for comments |
| 课程安排, 营期安排 | 引发需求 / 结尾升华 | explains why today's lesson matters in the journey | becomes a long administrative detour |
| 案例佐证, 学员案例 | 引发需求 / 挖掘痛点 / 原理讲解 / 结尾升华 | proves relevance, consequence, method, or action value | stacks outcomes without linking to method |
| 自测, 体验测试 | 引发需求 / 挖掘痛点 / 原理讲解 / 实操演示 | creates personal relevance and a before-reference | makes unsupported diagnosis or fear |
| 讲解原理, 机制, 理论 | 原理讲解 | becomes a simple model, standard, or process | turns into terminology or background dumping |
| 真人模特, 跟做, 实操教学 | 案例应用/实操演示 | includes steps, judgment, validation, mistakes, and transfer | only shows the teacher doing it |
| 注意事项, 禁忌, 安全提醒 | 案例应用/实操演示 / 总结回顾 | blocks misuse and clarifies boundaries | appears late without relation to action |
| 实操总结, 调理总结, 课程回顾 | 总结回顾 | compresses what to remember and do | introduces new authority or new topics |
| 学习规则, 助教承接 | 结尾升华 | makes feedback and action low-resistance | pressures learners without learning value |
| 今日作业, 打卡要求 | 结尾升华 | states task, format, standard, reason, feedback | only tells learners to submit |
| 明日预告, 下节课预告 | 结尾升华 | connects next lesson to today's learning gap | becomes unrelated promotion |
| 结束语, 使命表达 | 结尾升华 | echoes today's value and reinforces action | becomes slogan or hard sell |

## Judgment Sentences

Use direct but actionable language:

```text
这里标题叫“案例佐证”，但实际承担的是“引发需求”：它让学员相信自己也需要这项能力。
```

```text
这里标题叫“调理总结”，但内容引入了新的权威和来源，实际没有完成“总结回顾”的记忆压缩。
```

```text
这里的“明日预告”可以归入结尾升华，但必须先说明明天解决今天哪个未完成的能力缺口。
```

## Main-Line Interference Flags

Mark as interference when any label:

1. interrupts principle or practice without improving comprehension
2. repeats rewards more than it clarifies action
3. relies on pressure instead of learning reason
4. adds a new topic after the summary
5. creates health, business, or outcome promises that increase compliance risk

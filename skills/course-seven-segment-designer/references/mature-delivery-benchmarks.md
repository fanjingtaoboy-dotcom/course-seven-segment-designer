# Mature Delivery Benchmarks

Use this reference for mature training-camp delivery scripts, real teacher transcripts, or "already works but can be optimized" materials.

This file contains anonymized patterns only. Do not copy private transcripts, teacher names, institution names, exact cases, or proprietary wording into public outputs unless the user explicitly allows publication.

## What Mature Delivery Scripts Often Already Do Well

1. They open with live-state confirmation, quick relationship building, and a reason to stay.
2. They translate broad wishes into one lesson goal.
3. They give learners an early bodily/business/behavioral self-test or visible experience.
4. They teach through one or more practice loops, not only concepts.
5. They use cases to build confidence and persistence.
6. They attach homework to assistant feedback or group submission.
7. They connect the next lesson to continued learning.

## Why Mature Does Not Automatically Mean 9

Mature delivery can still lose structural points when:

1. authority, rewards, cases, and course management crowd the main learning line
2. need activation stays at "what do you want" rather than "why today's ability matters"
3. pain excavation becomes fear or consequence without misconception and cause
4. principle and practice are interleaved so heavily that learners cannot retell the model
5. practice shows many actions but misses intermediate judgment, retest, mistake warnings, or transfer
6. summary repeats content but does not form a memory hook
7. homework and next-session preview are clear but not tied to today's learning gain
8. high-stakes claims create trust or compliance resistance

## Benchmark Pattern: Two-Loop Training-Camp Lesson

Some strong D1 delivery lessons use this structure:

```text
Opening trust
-> learner goal and camp map
-> quick test/experience
-> principle of the method
-> practice loop 1: visible symptom or task
-> bridge: why one visible result is not enough
-> practice loop 2: deeper maintenance/root cause
-> safety and mistake reminders
-> memory summary
-> homework + feedback + next lesson continuation
```

When diagnosing this pattern, do not split it into extra top-level modules. Treat both practice loops as part of segment 5, with local principle bridges where needed.

## Compare Different Teachers

When two mature scripts have different teachers:

1. Do not rank by personality, warmth, speed, or style alone.
2. Compare whether each teacher completes the same learner shift.
3. Separate "speaker flavor" from "course structure".
4. Extract reusable assets: strong opening moves, demand framing, practice-loop design, correction language, homework closure.
5. Flag risks that are transferable: overpromising, excessive authority, reward interference, insufficient summary, weak action standard.

## 7-to-9 Upgrade Lens

For a mature delivery script, focus on:

1. one clean main line
2. bridge quality between pain, principle, and practice
3. retellable model
4. before/during/after validation
5. mistake and boundary reminders
6. summary as memory structure
7. homework as low-resistance feedback loop
8. next lesson as logical continuation, not only reminder

# Scoring Rubric

## Scoring Process

Formal scoring must be observable and evidence-based. Do not score from overall feeling first.

```text
第一步：确认资料边界
第二步：识别七段一级结构
第三步：逐段核查二级任务
第四步：判断全课主线和七段咬合
第五步：检查案例/实操转化、总结记忆、结尾行动
第六步：套入 1/3/5/7/9 档位锚点
第七步：用“不能升档规则”反向校验
```

Every scoring answer must include:

```text
总分：
最接近的评分锚点：
不能给更高分的原因：
如果要升一档，最先要补的二级任务：
```

Distinguish:

| Judgment type | Concern | Cannot be replaced by |
|---|---|---|
| existence | whether the seven modules appear | functional qualification |
| function | whether each module completes secondary tasks | nice wording |
| closure | whether learners understand, can use, remember, and act | quantity of teaching |

For mature delivery scripts, do not score from "成熟感" or known business results. If two courses face different learner groups, do not use outcome data for cross-course scoring unless the user explicitly asks for operational analysis and provides comparable context. Score the observable structure: main line, segment coupling, practice validation, memory compression, and action closure.

## Score Bands

| Score | Structure | Secondary tasks | Learner result | Typical performance |
|---|---|---|---|---|
| 1 | seven segments uncontrolled or severely missing | secondary tasks mostly invalid | learner does not know the core lesson task | authority, emotion, vague promises, scattered actions |
| 3 | seven-segment shadow exists but many mismatches | most modules only surface actions | learner feels lively/content-rich but no stable loop | wish collection as need, anxiety as pain, action demo as transfer |
| 5 | seven segments mostly present but main line messy | some tasks done, some missing | learner can follow some actions but may not remember core flow | opening, pain, principle, practice exist but many side branches |
| 7 | clear sequence and focused main line | most tasks completed | learner takes away basic flow and can finish homework | clear goal, learning reason, pain cause, retellable flow, action standard |
| 9 | stable segment coupling and natural psychological progression | tasks complete with wording landing points | learner understands, practices, remembers, and acts | one main line, few key objects, clear flow, mistake reminders, action standard, next-step loop |

## Mature but Optimizable

A mature delivery script often starts near the 7-point diagnostic conversation, but it can still be capped below 9 by these issues:

1. It delivers an in-class experience but the summary does not make the method easy to retell.
2. It has homework but lacks a precise quality standard or feedback criterion.
3. It motivates next-session attendance but relies too much on rewards, authority, or pressure.
4. It has rich cases but does not bind them to one method model.
5. It uses strong outcome language that increases trust or compliance resistance.

## Five-Dimension Evidence Table

Use the five dimensions as evidence for final band; do not mechanically average.

| Dimension | 1 | 3 | 5 | 7 | 9 |
|---|---|---|---|---|---|
| 一级结构完整度 | lost/missing | shadow but mismatched | mostly complete | clear order | stable coupling |
| 二级任务完成度 | mostly invalid | mostly surface actions | partial completion | mostly complete | complete with wording landing |
| 主线聚焦度 | authority/emotion/rewards/actions mixed | theme exists but scattered | visible but multi-line | basically focused | one main line throughout |
| 能力转化度 | scattered demos or urging | action exists but lacks judgment/validation | can follow, unstable reproduction | takes away basic flow | understands, practices, transfers |
| 记忆与行动闭环 | empty ending/task only | homework but weak standard | summary and homework but weak value loop | flow summary and standard | summary, mistakes, action, and continuity complete |

Banding rules:

1. Low-band priority: a clearly low key dimension blocks higher scoring.
2. Closure priority: for practice courses, missing two or more of steps + judgment + validation + mistakes + homework standard usually caps at 5.
3. Main-line priority: if rewards, credentials, side cases, vague promises, or irrelevant content consume large space, usually cap at 5 even if all segments appear.
4. Secondary-task priority: top-level module labels or surface actions do not qualify a module.
5. Same-word-count calibration: do not give a higher score just because a version is longer.

## Cannot-Upgrade Rules

| Intended score | Blocking problem | Highest suggested |
|---|---|---|
| above 3 | seven titles exist but learner cannot state the core lesson task | 1 |
| above 5 | 引发需求 only asks for problems/wishes and does not create learning reason | 3 |
| above 5 | 挖掘痛点 only creates anxiety without cause, misconception, and learning necessity | 3 |
| above 7 | 原理讲解 is knowledge dump without retellable model or judgment standard | 5 |
| above 7 | 实操 only shows teacher action without before reference, process judgment, after validation | 5 |
| above 7 | 总结 only repeats directory/points and does not create memory structure | 5 |
| above 7 | 结尾 only assigns homework without action motive, standard, and low-resistance next step | 5 |
| 9 | segments qualify but expression is still template-like or value connection unnatural | 7 |
| 9 | learners can follow but cannot transfer to self/family/business scenes | 7 |
| 9 | course is mature in delivery but the main line is crowded by rewards, authority, or unrelated cases | 7 |
| 9 | next-session attendance and homework are clear, but not naturally derived from today's learning gain | 7 |

## Upgrade Path

| Current band | Upgrade key | Priority actions |
|---|---|---|
| 1 -> 3 | make seven segments at least recognizable | delete excessive self-praise, rewards, vague promises; add topic, need, pain, principle, practice, summary, action |
| 3 -> 5 | turn surface actions into a basic teaching loop | convert wish collection into learning reason; demo into steps; homework into standard |
| 5 -> 7 | turn teachable draft into qualified structure | tighten one main line, remove side branches, strengthen secondary tasks and coupling |
| 7 -> 9 | turn qualified draft into high-standard example | improve natural wording, case continuity, transfer, mistake reminders, and value/action closure |

## Judgment Sentence Library

| Object | Sentence |
|---|---|
| wish collection | 这只是“收集需求”，不是“引发需求”。学员报目标，不等于知道为什么要学这一课。 |
| problem-name collection | 学员报病名，只说明入口在哪里，不说明他知道先测什么、摸哪里、怎么验证。 |
| pain stimulation | 这只是“制造焦虑”，不是“挖掘痛点”。痛点必须拆出原因、误区和学习必要性。 |
| principle dumping | 这只是“知识堆叠”，不是“原理讲解”。原理必须形成可判断、可复述、可应用的模型。 |
| action demo | 这只是“老师做了一遍”，不是“实操转化”。实操必须包含步骤、判断、反馈验证和易错提醒。 |
| point repetition | 这只是“点位复述”，不是“学习结构总结”。学员知道提过几个位置，不等于记住本课主线。 |
| homework assignment | 这只是“任务安排”，不是“行动动机”。学员知道要发作业，不等于知道为什么做、怎么做算合格。 |
| rewards/discipline | 奖励、纪律、助教安排不能单独成第八模块，只能按功能归入七段；如果不服务二级任务，就是主线挤占。 |

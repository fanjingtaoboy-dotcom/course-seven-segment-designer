# Seven-Segment Course Framework

## Overview

Use this framework for live courses, public classes, live training-camp lessons, and online topic lessons. It is not a slide template or word-for-word script template. It is the psychological progression behind a course.

```text
暖场破冰 -> 引发需求 -> 挖掘痛点 -> 原理讲解 -> 案例应用/实操演示 -> 总结回顾 -> 结尾升华
```

The learner should move through this chain:

```text
这节课值得听 -> 这和我有关 -> 这个问题需要解决 -> 原来逻辑是这样 -> 我知道怎么用 -> 我记住了 -> 我愿意课后行动或继续学习
```

## 5A Progression

| Segment | 5A shift | Learner shift | Core job |
|---|---|---|---|
| 暖场破冰 | A0 -> A1 | from unfamiliar/unmoved to aware/attentive | build initial trust, attention, and reason to keep listening |
| 引发需求 | A1 -> A2 | from watching to interested/expectant | make the learner feel the topic is about them |
| 挖掘痛点 | A2 -> A3 | from interested to urgent/wants solution | show why the problem matters and must be solved |
| 原理讲解 | A3 -> A4 | from wants solution to understands/trusts | explain why the method works |
| 案例应用/实操演示 | A3 -> A4 | from understands to can apply or practice | turn knowledge into usable ability |
| 总结回顾 | A4 consolidation | from learned to structured memory | compress the lesson into memorable structure |
| 结尾升华 | A4 reinforcement | from memory to motivation/action | connect value to a low-resistance next action |

## Persuasion Variables

Use these variables as supporting judgment, not as replacement for the seven segments:

```text
R = 相关力：learner feels "this is about me"
V = 价值力：learner sees why the lesson matters
T = 信任力：learner trusts the method, teacher, and evidence
A = 行动力：learner knows and wants the next action
F = 阻力：difficulty, distrust, over-marketing, anxiety, compliance, or action friction
```

Segment mapping:

```text
暖场破冰 + 引发需求 = R
挖掘痛点 = value awakening and urgency
原理讲解 = V + T
案例应用/实操演示 = proof of usability and ability transfer
总结回顾 = memory consolidation and action preparation
结尾升华 = A
```

## Mandatory Principles

1. Seven segments are a functional chain, not a mechanical template.
2. The segment order is fixed; duration, expression, and density may vary by course stage.
3. Courses should pursue understanding, skill, memory, and action intention, not only conversion.
4. For each segment, judge existence, qualification, and fit with adjacent segments.
5. Diagnosis and generation must go below top-level segment names into secondary tasks and wording landing points. Formal scoring, deep diagnosis, and reconstruction must use tertiary acceptance checks.
6. 暖场破冰 is not idle chat. 结尾升华 is not slogan shouting. 原理讲解 is not knowledge dumping.
7. Segment 5 is either 案例应用 for non-practice courses or 实操演示 for practice courses.
8. Course design depends on learner information. If learner data is missing, give cautious inferred analysis and list the missing materials.
9. Control resistance throughout.
10. Rewards, discipline, assistant arrangements, homework reminders, and previews must not become an eighth module.

## Quick Checklist

| Segment | Core question | Qualified signal |
|---|---|---|
| 暖场破冰 | Will learners continue listening? | They know topic, teacher relevance, and why they should listen |
| 引发需求 | Do learners feel this is about them? | Real scene, goal, gap, or curiosity trigger |
| 挖掘痛点 | Do learners feel it must be solved? | Specific pain, clear consequence, urgency without fearmongering |
| 原理讲解 | Can learners understand why? | Clear concepts, logic, analogy, steps, or standards |
| 案例应用/实操演示 | Can learners see how to use it? | Case analysis or action demonstration from "understand" to "can do" |
| 总结回顾 | Can learners remember the key structure? | Framework, key restatement, memory hook, and mistake reminder |
| 结尾升华 | Will learners act after class? | Value echo, concrete action, low-resistance next step |

## Secondary Tasks

| Segment | Secondary tasks | Wording landing point |
|---|---|---|
| 暖场破冰 | live-state confirmation; learner scene activation; topic orientation; initial trust; demand entry | "Class has started; this is about me; the teacher is worth hearing; the next part matters" |
| 引发需求 | receive surface need; summarize shared goal; point out knowledge/ability gap; present lesson benefit; lead to pain excavation | "I have a problem" -> "I need this lesson" |
| 挖掘痛点 | present old practice/phenomenon; explain causes; show consequence/cost; correct common misconception; leave principle entry | "This matters and I need to understand it first" |
| 原理讲解 | define key concept; explain mechanism; give judgment standard; break into method/process; state boundaries; transition to application | "I understand why and know how to judge first" |
| 案例应用/实操演示 | define application object; demonstrate standard steps; reveal intermediate judgment; set feedback validation; warn mistakes; guide transfer/practice | "I can imitate, judge, and practice" |
| 总结回顾 | extract core points; reorganize as formula/checklist/three points; return to opening problem; remind mistakes; prepare action | "I remember the most important structure" |
| 结尾升华 | echo lesson gain; connect deeper value; give low-resistance action; state action standard; connect next lesson/practice; confirm action | "I know what to do tonight" |

## Segment Boundaries

### 引发需求 vs 挖掘痛点

| Question | Classification |
|---|---|
| Does this mainly make learners feel "this is related to me and I want to hear it"? | 引发需求 |
| Does this mainly make learners feel "I cannot ignore this and must solve it"? | 挖掘痛点 |
| If removed, learners know the topic but not why they need it | 引发需求 missing |
| If removed, learners are interested but not urgent | 挖掘痛点 missing |

Use order: first evoke learner relevance and goal; then reveal causes, consequences, and learning necessity.

### 原理讲解 vs 案例应用/实操演示

| Question | Classification |
|---|---|
| Does this answer "why is it like this"? | 原理讲解 |
| Does this answer "how do I use it in a concrete case/action"? | 案例应用/实操演示 |
| If removed, learners do not know the method logic | 原理讲解 missing |
| If removed, learners understand but cannot operate or transfer | 应用/实操 missing |

Use order: explain principle first, then apply it.

### 总结回顾 vs 结尾升华

| Question | Classification |
|---|---|
| Does this help learners remember what they learned? | 总结回顾 |
| Does this motivate after-class action or continued learning? | 结尾升华 |
| If removed, learners do not know the key points | 总结回顾 missing |
| If removed, learners know the key points but lack action motivation | 结尾升华 missing |

Use order: summarize first, then elevate into action.

## Coupling Checks

| Link | Check |
|---|---|
| 暖场破冰 -> 引发需求 | Does the opened topic become a real learner need? |
| 引发需求 -> 挖掘痛点 | Do the scenes/goals reveal causes and consequences? |
| 挖掘痛点 -> 原理讲解 | Does the principle answer the pain just raised? |
| 原理讲解 -> 应用/实操 | Is the principle used to analyze cases or guide actions? |
| 应用/实操 -> 总结回顾 | Are key methods compressed into memorable structure? |
| 总结回顾 -> 结尾升华 | Does the summary connect naturally to value and action? |
| full chain -> 5A | Does the learner move from unfamiliar to attentive, interested, urgent, understanding, able, remembering, and acting? |
| full chain -> resistance | Does the course avoid being too hard, empty, anxious, salesy, or overpromising? |

## Non-Main-Thread Content

| Content | Proper location | Qualified use | Unqualified use |
|---|---|---|---|
| arrival interaction, sound check, welcome | 暖场破冰 | helps learners enter class and quickly return to topic | long greeting that does not point to the lesson |
| rewards, gifts, lotteries | 暖场破冰 or 结尾升华 | light incentive for attendance or completion | frequent interruption of need, pain, principle, or practice |
| learner wish poll | 引发需求 | turns wishes into learning reasons | only collects wishes |
| discipline, "do not leave", persistence | 挖掘痛点 or 结尾升华 | clarifies why practice matters or supports after-class action | blame, pressure, moral judgment |
| assistants, check-ins, comments | 实操演示 or 结尾升华 | supports correction and practice loop | replaces teaching summary |
| completion code, reward method | 结尾升华 | brief after action explanation | interrupts principle or practice |
| next lesson preview | 结尾升华 | connects today's gain to next learning | steals the summary or becomes hard selling |

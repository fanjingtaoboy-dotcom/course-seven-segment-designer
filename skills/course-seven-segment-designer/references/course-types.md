# Course Types: Training-Camp Single Lessons and Delivery Classes

Use this reference when the user mentions 训练营单课, D1/D2/Dn, 交付课, practice delivery, homework, next-session attendance, assistant follow-up, or course retention.

## Core Distinction

| Type | Primary job | Typical secondary jobs | Main risk |
|---|---|---|---|
| 训练营单课 | complete one visible learning/practice win inside a multi-day journey | next-session attendance, homework, group activity, assistant handoff | attendance/rewards overwhelm the lesson |
| 交付课 | help learners understand, practice, remember, and execute | confidence, correction, progress evidence, continued practice | content feels rich but learners cannot reproduce |
| D1 训练营单课 | build first trust and first action | explain camp map, lower difficulty, create first homework | too much authority, welfare, and discipline before the learner has a win |

If the user gives a priority order, use it. If not, default to:

```text
交付效果 -> 持续学习/次日到课 -> 交作业/反馈闭环
```

Do not treat 次日到课, 奖励, 作业, 助教, or 福利 as top-level course modules. They must support one of the seven segments.

## Success Standard

A strong training-camp delivery lesson lets the learner say:

```text
我知道今天解决什么 -> 我知道为什么要学 -> 我能跟着做一次 -> 我知道哪里算做对 -> 我知道今晚交什么 -> 我知道明天为什么要来
```

## Seven-Segment Jobs by Course Type

| Segment | Training-camp single lesson | Delivery class |
|---|---|---|
| 暖场破冰 | fast trust, attendance state, first-day relationship, topic promise | reconnect prior learning and current task |
| 引发需求 | convert learner wishes into today's learning goal | connect current problem to the skill being practiced |
| 挖掘痛点 | reveal old behavior, misconception, or consequence that makes learning necessary | show why unguided practice fails |
| 原理讲解 | give the smallest model needed to believe and judge the method | make principles retellable and usable |
| 案例应用/实操演示 | produce a first observable practice experience | demonstrate standard steps, intermediate judgment, validation, and correction |
| 总结回顾 | compress the day's method into a memory hook | turn scattered content into a checklist learners can reuse |
| 结尾升华 | connect today's win to next lesson and a low-resistance homework action | specify homework, standard, feedback channel, and next practice |

## Delivery Priority Checks

### 交付效果

Ask:

1. Does the learner know the exact object of practice?
2. Does the learner know the step order?
3. Does the learner know how to judge before, during, and after the action?
4. Does the lesson normalize first-attempt imperfection without removing responsibility to practice?
5. Does the lesson include boundaries, contraindications, or "when not to do this" where needed?

### 次日到课

Qualified next-session motivation should:

1. connect tomorrow to today's unfinished learning loop
2. show why the next lesson completes or deepens today's method
3. avoid making fear, scarcity, or rewards the only reason to return

### 交作业

Qualified homework should include:

1. one concrete task
2. one visible submission format
3. one quality standard
4. one feedback path
5. one reason the task improves learning or results

## Pacing Guidance

Use proportions as a heuristic, not as a rigid rule.

| Segment group | 训练营单课 tendency | Delivery-class tendency |
|---|---:|---:|
| 暖场 + 引发需求 | 15%-25% | 10%-18% |
| 挖掘痛点 + 原理讲解 | 25%-35% | 25%-40% |
| 案例/实操 | 30%-45% | 35%-50% |
| 总结 + 结尾 | 12%-20% | 12%-22% |

If the course has two practice loops, diagnose each loop separately, then judge whether the second loop extends the first or competes with it.

## Common Optimization Moves

| Symptom | Likely cause | Rewrite move |
|---|---|---|
| Learners interact a lot but do not submit homework | interaction creates atmosphere but not action standard | restate homework as object + format + standard + feedback |
| Learners attend tomorrow only for rewards | next-session value is not tied to today's learning loop | connect tomorrow to the skill gap exposed today |
| Mature teacher sounds persuasive but structure feels crowded | authority, cases, rewards, and theory all compete for attention | preserve proof points, compress repeated claims, restore one main line |
| Learners can follow in class but cannot repeat after class | practice lacks intermediate judgment and mistake warnings | add before/during/after validation and "three common mistakes" |

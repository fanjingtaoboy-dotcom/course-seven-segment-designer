# Diagnosis Rubric

## Required Judgments

For each segment, diagnose four layers:

```text
结构判断：surface content belongs to which top-level segment; whether there is module misclassification
任务判断：which secondary tasks are qualified, partial, or missing
心理判断：which learner psychological shift succeeds or fails
验收判断：which decisive tertiary checks are qualified, partial, or missing
```

Quick screening may stop at secondary tasks. Formal scoring, deep transcript diagnosis, reconstruction, and optimized wording must use tertiary checks.

## Secondary Task Table

Minimum table:

| 二级任务 | 原稿证据 | 判定 | 缺口 | 对心理推进的影响 |
|---|---|---|---|---|
| task | original sentence or behavior | 达标 / 部分达标 / 缺失 | what is missing | where the learner gets stuck |

## Tertiary Acceptance Table

Minimum table:

| 二级任务 | 三级验收点 | 原稿证据 | 判定 | 扣分点 | 改稿动作 |
|---|---|---|---|---|---|
| key task | what completion requires | original sentence or behavior | 达标 / 部分达标 / 缺失 | missing acceptance point | wording or structure to add |

Do not mechanically fill every tiny item. Cover the checks that affect scoring and rewrite decisions.

## Tertiary Check Summary

### 暖场破冰

| Secondary task | Acceptance checks |
|---|---|
| 直播状态确认 | confirms sound/visual/online state; enters topic quickly; avoids repeated waiting and invalid "1" prompts |
| 学员场景唤起 | names target identity, scene, body/business feeling; creates "this is about me" |
| 主题定向 | states lesson topic in one sentence; avoids only saying "important/valuable/systematic" |
| 初始信任 | uses relevant experience, observation, case, or boundary; avoids resume dumping and vague self-praise |
| 需求入口 | leaves scene, problem, goal, or suspense; naturally enters 引发需求 |

### 引发需求

| Secondary task | Acceptance checks |
|---|---|
| 接住表层需求 | receives learner's named problem, wish, goal, or scene; makes the problem feel seen |
| 归纳共同目标 | turns scattered needs into shared learning goal |
| 点出知识/能力缺口 | explains why naming a problem/wish is not enough; identifies missing judgment, positioning, process, expression, or retest ability |
| 呈现本课收益 | states the concrete judgment, method, action, or wording the lesson gives |
| 承接挖掘痛点 | leaves "what happens if not learned / why old method is insufficient" entry |

### 挖掘痛点

| Secondary task | Acceptance checks |
|---|---|
| 呈现旧做法或现象 | recreates real old behavior; avoids abstract problem labels only |
| 拆解问题原因 | explains why old behavior fails; moves from phenomenon to cause |
| 说明后果或代价 | clarifies learning/action/business/body cost; avoids excessive fear |
| 纠正常见误区 | points out common misjudgment and binds it to the lesson task |
| 留下原理入口 | naturally raises "why this happens / what correct model is" |

### 原理讲解

| Secondary task | Acceptance checks |
|---|---|
| 定义核心概念 | defines necessary concepts; avoids term stacking |
| 解释问题机制 | explains how the problem happens and why it affects results; learner can retell |
| 给出判断标准 | tells learners what to observe/measure/judge |
| 拆出方法流程 | compresses method into steps, formula, model, or process serving practice |
| 说明适用边界 | states who it fits/does not fit, when to reduce/stop/be cautious; avoids absolute promises |
| 转入应用或实操 | passes principle naturally into case/action instead of jumping away |

### 案例应用/实操演示

| Secondary task | Acceptance checks |
|---|---|
| 明确应用对象 | states scene/problem/person/action this step applies to |
| 标准步骤示范 | clear order; learner knows first, second, third steps |
| 展示中间判断 | explains how to judge correct/deviated execution during process |
| 设置反馈验证 | includes before reference and after validation using same standard |
| 提醒易错动作 | warns common mistakes, risks, and boundaries; avoids "more pain/more quantity is better" |
| 引导迁移或复练 | explains self-use, family use, store use, or after-class practice |

### 总结回顾

| Secondary task | Acceptance checks |
|---|---|
| 提炼核心重点 | compresses to 1-3 key points; avoids re-teaching everything |
| 重组成口诀/清单/三点 | creates memorable structure learners can retell |
| 回扣开头问题 | answers the opening scene/problem |
| 提醒易错点 | reminds most likely misuse, misremembering, or omission |
| 铺垫课后行动 | turns naturally to homework/next action instead of sudden assignment |

### 结尾升华

| Secondary task | Acceptance checks |
|---|---|
| 回扣本课收获 | action is based on what was learned; avoids new unrelated topic |
| 连接深层价值 | explains why the work is worth doing; answers deeper need |
| 给出低阻力行动 | gives one clear simple executable step; avoids heavy task load |
| 说明行动标准 | states what counts as qualified; assistant/learner can check |
| 承接下一课或持续练习 | explains relationship between today and next step; avoids hard sell |
| 行动确认 | asks for commitment/submission/practice/feedback in low-pressure way |

## Common Misjudgments

| Surface action | Often misjudged as | Actual problem |
|---|---|---|
| asking learners to report problems/wishes | 引发需求 | only collects needs; does not explain why this lesson is needed |
| saying "this is important" | 挖掘痛点 | only states conclusion; no cause, consequence, or learning necessity |
| teaching much professional knowledge | 原理讲解 | principle must become a judgeable, retellable, usable model |
| teacher demonstrates once | 实操演示 | demonstration must include steps, intermediate judgment, validation, and mistakes |
| restating what was taught | 总结回顾 | directory repetition is not summary; must create memory structure |
| assigning homework | 结尾升华 | homework is not elevation unless it includes value, standard, and action reason |

## Main Problem Deep-Dive

Every major problem must include six layers:

1. 表面动作: what the original content does.
2. 结构误判: what it looks like it completed but did not.
3. 本质缺口: which secondary task is missing.
4. 三级缺口: which acceptance check is missing.
5. 心理推进失败: which learner shift fails.
6. 后续影响: which later segment becomes weak if not fixed.

Use precise judgment sentences:

```text
这只是“收集需求”，不是“引发需求”。学员报病名，只说明他知道自己有什么问题，不等于他知道为什么要学这一课。
```

```text
这只是“知识堆叠”，不是“原理讲解”。原理必须形成可判断、可复述、可应用的模型。
```

```text
这只是“任务安排”，不是“行动动机”。学员知道要发作业，但还不清楚为什么这个作业重要、作业检查什么、做到什么程度算合格。
```

## Recommendation Type Translation

Never list type names alone. Translate each type into rewrite work:

| 推荐类型 | 为什么选 | 在本稿中承担的改稿任务 | 具体话术动作 |
|---|---|---|---|
| 三点复盘型 | information overload | compress the lesson into one main line, two positions, five-step flow | start with "今天只带走三件事" |
| 流程口诀型 | practice must be repeated after class | compress actions into a formula such as "测、找、暖、松、看" | state the formula and explain each step |
| 易错提醒型 | learners may misuse after class | block "pressing too hard, chasing pain, no retest" | close with "三个不要" |

After optimized wording, map key sentences:

| 优化话术关键句 | 对应类型 | 修复的二级任务 | 学员心理变化 |
|---|---|---|---|
| key sentence | type | secondary task | from X to Y |

## Strict Judgment Language

| Situation | Avoid | Use |
|---|---|---|
| surface action exists but core task missing | 偏弱 / 可加强 | 不合格 |
| proportion below half of suggested lower bound | 略轻 | 严重不足 |
| homework exists but no action meaning or standard | 基本合格 | 有任务安排，但结尾升华不合格 |
| summary only restates content | 部分合格 | 这是目录/点位复述，不是学习结构总结 |
| interaction exists but no psychological progress | 互动不错 | 互动存在，但没有完成本段核心推进 |

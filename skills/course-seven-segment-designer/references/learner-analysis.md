# Learner Analysis, Stage, and Pacing

## Learner Analysis Card

Build this card before firm design, diagnosis, scoring, or reconstruction:

```text
目标学员是谁：
学员当前处于什么场景：
学员当前心理起点是 A0/A1/A2/A3/A4 中哪一类：
课程阶段类型是 D1破冰 / 知识交付 / 营销转化 中哪一类：
课程类型是 训练营单课 / 交付课 / 公开课 / 专题课 中哪一类：
学员已有认知基础是什么：
学员遇到的表层痛点是什么：
痛点背后的深层需求是什么：
本节课希望学员记住什么：
本节课希望学员理解什么：
本节课希望学员掌握或应用什么：
课程希望学员课后做什么下一步行动：
本节课的优先级排序是什么：
学员不行动或学不会的主要阻力是什么：
这些判断来自用户提供资料、原稿证据，还是推断：
```

## Missing Information Rules

If learner data is incomplete:

1. Infer target learner, scene, pain point, and psychological starting point from the source material when possible.
2. Mark all inferred judgments as inference.
3. Do not write uncertain judgments as confirmed facts.
4. Give a conservative general version if useful.
5. List the learner information needed to raise accuracy.
6. If target learners are too different, split into separate course versions or cases instead of forcing one course to hit everyone.

## How Learner Data Affects Segments

| Learner data | Affected segments | Check |
|---|---|---|
| learner identity/role | 暖场破冰 | Does the opening signal "this class is for me"? |
| psychological starting point | 暖场破冰, 引发需求 | Is the course building from unfamiliarity or extending existing interest? |
| typical scene | 暖场破冰, 引发需求 | Does it use real scenes to create identification? |
| surface pain point | 引发需求, 挖掘痛点 | Is the pain concrete and relevant to this lesson? |
| deeper need | 结尾升华 | Does the value statement answer the learner's desired change? |
| teaching goal | 原理讲解, 应用/实操, 总结回顾 | Does the course distinguish remember, understand, master, and apply? |
| live scene | all | Does it manage device checks, attendance, attention, and rhythm? |
| lesson duration | all | Are segment proportions reasonable? |
| target action | 结尾升华 | Is the homework/practice/consultation/purchase low-resistance and clear? |
| priority order | all, especially 总结回顾 and 结尾升华 | Does the course protect the primary goal instead of letting secondary goals compete with it? |

## Typical Failures from Weak Learner Analysis

1. Opening mismatch: teacher introduces themselves, but learners do not know why it matters.
2. Empty need: says "important" without a real learner scene.
3. Over-heavy pain: creates anxiety without enough method or understanding.
4. Over-hard principle: feels like a textbook.
5. Missing application: learners understand but do not know how to use it.
6. Weak summary: no memory hook, so the lesson is forgotten.
7. Misaligned elevation: ending is emotional or salesy but does not echo lesson value.

## Course Stage Types

The seven segments remain fixed, but weight changes by stage:

| Course stage | Main learner psychology | Design focus |
|---|---|---|
| D1 破冰建立信任 | A0, A1 | move from unfamiliar to interested; build trust |
| 知识交付 | A1, A2 | deepen interest; teach core knowledge; stimulate continued learning |
| 营销转化 | A2, A3 | move from inquiry to action; create reasonable urgency and conversion reason |
| 训练营单课 | A0-A3 depending on day | complete one visible learning win while supporting attendance and homework |
| 交付课 | A1-A4 | teach for understanding, practice, memory, and feedback closure |

| Segment | D1 trust-building | knowledge delivery | marketing conversion |
|---|---|---|---|
| 暖场破冰 | build first impression and welcome | strengthen teacher-student relationship | prepare demand and action |
| 引发需求 | create interest | deepen demand and learning necessity | bind personal need to solution/product |
| 挖掘痛点 | create urgency | reveal deeper problem | connect pain to product/system value |
| 原理讲解 | establish basic cognition | deepen mechanism | support value proposition |
| 案例应用/实操演示 | simple application and confidence | improve application ability | show higher-level content and desire |
| 总结回顾 | strengthen learning confidence | consolidate knowledge | reinforce value and action reason |
| 结尾升华 | encourage continuous learning | encourage persistence | push immediate reasonable action |

For 训练营单课 and 交付课, also read `course-types.md`.

## Pacing Reference

Use proportions as judgment guidance, not a rigid formula.

| Segment | Common range | Over-heavy risk | Over-light risk |
|---|---:|---|---|
| 暖场破冰 | 5%-8%, usually max 5 minutes in long classes | idle chat, self-praise, slow rhythm | weak relationship and attention |
| 引发需求 | 10%-18% | stays in wishes, never enters problem | learners feel unrelated |
| 挖掘痛点 | 12%-22% | fearmongering or sales pressure | no urgency |
| 原理讲解 | 20%-30% | knowledge dump, too hard | learners do not know why method works |
| 案例应用/实操演示 | 18%-28% | too detailed, squeezes summary/action | learners understand but cannot use |
| 总结回顾 | 6%-12% | repeats the lesson | learners cannot remember key points |
| 结尾升华 | 5%-15% | slogan, sentimentality, hard sell | no action motivation |

Weighted duration guide:

| Segment | D1 first class | knowledge delivery | marketing conversion |
|---|---:|---:|---:|
| 暖场破冰 | 0.6 | 0.5 | 0.5 |
| 引发需求 | 1.6 | 1.0 | 1.2 |
| 挖掘痛点 | 1.8 | 1.2 | 1.8 |
| 原理讲解 | 1.8 | 2.2 | 1.5 |
| 案例应用/实操演示 | 1.5 | 1.8 | 1.2 |
| 总结回顾 | 0.8 | 1.0 | 1.0 |
| 结尾升华 | 0.8 | 0.6 | 1.2 |

```text
模块时长 = （总时长 × 模块权重）÷ 总权重
```

Round and adjust to fit total duration. Check the opening separately; a long course does not justify unlimited opening.

## Pacing Diagnosis Output

When pacing matters, output:

```text
七段占比判断：
过重段落：
过轻段落：
对 5A 心理推进的影响：
对学习效果的影响：
调优动作：
```

If exact word counts or timestamps are unavailable, use "偏重 / 适中 / 偏弱 / 缺失".

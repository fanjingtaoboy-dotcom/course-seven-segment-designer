# Calibration Cases

Use these anchors when a score needs calibration, especially for D1 trust-building live classes. Same-word-count calibration matters: score differences should come from structure quality, secondary-task completion, wording landing points, focus, practice validation, and action closure, not from length.

## 1-Point Anchor

Judgment:

```text
不是“缺七段”，而是“七段功能失效”。
```

Signals:

1. Opening has device checks, credentials, greetings, rewards, but weak topic orientation.
2. Need segment collects self-use/family/store/business wishes without turning them into "why learn this lesson".
3. Pain has catchy lines but does not stabilize into judgment, positioning, and retest gaps.
4. Practice contains actions, but body parts, tools, rewards, cases, and vague promises are mixed.
5. Summary repeats points; ending gives tasks/previews without action motive.

Why 1:

```text
同等字数下，大量篇幅消耗在权威、热闹、泛承诺、奖励和散动作上。学员可能觉得课堂热闹，但很难说清今天到底要带走什么核心流程。
```

Why not 3:

```text
七段虽然有标题和局部内容，但核心功能没有稳定成立。引发需求、实操演示、总结回顾和结尾升华没有形成学习闭环。
```

## 3-Point Anchor

Judgment:

```text
表面动作像对了，但多数模块只完成了表层任务。
```

Signals:

1. Opening states the topic.
2. Need distinguishes learner goals but mainly collects goals.
3. Pain begins to discuss old ineffective methods, but cause analysis is unstable.
4. Principle has concepts but not a clear judgment model.
5. Practice has test, find, warm, loosen, retest, but lacks process judgment, correction, transfer.
6. Summary/homework exist but learners still depend on teacher guidance.

Why 3:

```text
学员会觉得有内容、有动作、有互动，但不一定形成稳定学习闭环。它比 1 分更像一节课，但七段之间错位明显，二级任务多处只完成表面动作。
```

Why not 5:

```text
引发需求仍偏愿望收集，挖掘痛点没有持续压到学习必要性，实操转化缺少足够判断和验证，学员课后复现不稳。
```

## 5-Point Anchor

Judgment:

```text
七段基本齐全，可以讲，但主线和记忆闭环还不稳。
```

Signals:

1. Opening can state the lesson task.
2. Need begins to turn use cases into learning goals.
3. The analysis can identify that reporting problems is not yet need activation.
4. Principle compresses into a basic flow or model.
5. Practice completes basic actions.
6. Ending has homework requirements and standard.

Why 5:

```text
它已经可以作为一节基本可讲的课。学员能跟做，也能听到核心流程。但旁支信息仍容易并行，课后记忆和复现不够稳。
```

Why not 7:

```text
主线虽然可见，但不够干净；实操虽然能跟做，但中间判断、易错提醒、迁移应用和总结压缩还不够稳定。
```

## 7-Point Anchor

Judgment:

```text
七段顺序清楚，主线基本聚焦，大部分二级任务完成。
```

Signals:

1. Opening directly orients the core task.
2. Need explains learning reasons for different learner contexts.
3. Pain exposes misconceptions, not just symptoms.
4. Principle becomes a retellable model and process.
5. Practice includes before test, steps, retest, transfer, and homework standard.
6. Summary extracts main line, key objects, actions, and process.
7. Ending gives low-resistance homework and qualification standard.

Why 7:

```text
学员能带走一套基础流程，并知道今晚如何完成作业。多数二级任务已经完成，七段咬合基本成立。
```

Why not 9:

```text
局部表达仍偏标准框架化，案例、情绪流动和价值承接还可以更自然。它是合格可用稿，不是高标准示范稿。
```

## 9-Point Anchor

Judgment:

```text
七段稳定咬合，二级任务完整，学员能理解、上手、记住并行动。
```

Signals:

1. Opening states one lesson task.
2. Need states why problem naming/wish reporting is not enough and defines the real ability gap.
3. Pain decomposes structural misconceptions.
4. Principle uses one core model and one verification logic.
5. Practice includes steps, intermediate judgment, feedback validation, mistakes, and transfer.
6. Summary compresses into main line, key objects, actions, process, and mistakes.
7. Ending gives action options, submission order, qualification standard, assistant check points, and next lesson connection.

Why 9:

```text
它不是句子更漂亮，而是每一段都承担明确二级任务，且前后互相咬合。学员能从“我有问题”推进到“我知道为什么要学、怎么判断、怎么操作、怎么复测、今晚怎么交作业”。
```

Why not automatic 10:

```text
除非真实学员资料充分、讲师风格适配、案例证据真实、直播互动节奏也经过验证，否则 9 分已经是高标准示范。
```
